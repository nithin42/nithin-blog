# Nithin — Personal Blog & Portfolio

The personal blog and portfolio of **Nithin**, Cloud Developer & AI Solutions Architect. Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com), deployed to [GitHub Pages](https://pages.github.com/).

🌐 **Live Site**: [https://nithin42.github.io/nithin-blog/](https://nithin42.github.io/nithin-blog/)

---

## 🚀 Features

- ⚡ **Astro 5 + Tailwind CSS 4**: Near-zero JavaScript, sub-second page loads, and fully responsive.
- ✍️ **MDX Content Collections**: Blog posts with rich Markdown, code syntax highlighting, and responsive diagrams.
- 🛡️ **AI & Cloud Architecture**: Articles covering Azure OpenAI fine-tuning audits, automated Azure ML privacy governance gates, and multi-agent systems.
- 🏷️ **Curated Topic Hubs & Tags**: Explore articles by AI & Agents, Azure & Cloud, and Security & Identity.
- 🌗 **Dark / Light Mode**: Seamless theme switching with no flash on load.
- 💬 **Giscus Comments**: Community discussions powered by GitHub Discussions.
- 🎨 **Bespoke 3D AI Hero Banners**: Editorial 3D Fluent / Claymorphic diagrams.
- 📰 **RSS Feed & SEO**: Auto-generated `rss.xml`, sitemaps, Open Graph cards, and JSON-LD schema.
- 🚀 **Automated CI/CD**: One-click deployments via GitHub Actions.

---

## 🛠️ Tech Stack

- **Framework**: [Astro](https://astro.build)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **Typography & Icons**: Custom SVG Icon system & Lucide
- **Image Optimization**: [Sharp](https://sharp.pixelplumbing.com/) & Astro Image Assets (WebP responsive breakpoints)
- **Hosting**: GitHub Pages
- **Comments**: [Giscus](https://giscus.app)

## 💻 Getting Started Locally

### Prerequisites

- **Node.js** ≥ 20
- **npm** ≥ 10

### Installation

```bash
git clone https://github.com/nithin42/nithin-blog.git
cd nithin-blog
npm install
```

### Run Local Development Server

```bash
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser.

### Build for Production

```bash
npm run build
```
